왜 만들었나

만든 이유

요즘을 ‘각자도생의 시대’라고
합니다.

도로 위에서는 더 그렇습니다. 옆 차의 운전자는 비켜 가야 할 차일 뿐이고,
운전자끼리 주고받는 것은 경적과 상향등이 거의 전부입니다.

하지만 같은 길을 달리는 사람들은,
같은 하루를 견디고 있는 사람들입니다.

주목한 순간

하루 중 드물게,
혼자 있는 시간.

출퇴근길에는 그날 있었던 일과 감정이 가장 많이 떠오릅니다.
하지만 손도 눈도 쓸 수 없어 적지 못하고, 차에서 내리면 사라집니다.

  • “아 오늘 하루도 고생했다. 어서 집에 가서 쉬자.”
  • “팀장한테 깨지고, 야근도 하고… 힘들다.”
  • “엄마한테 전화나 해 볼까. 괜히 보고 싶네.”
  • “아 비 오니까 길 진짜 막힌다. 어떡하지 진짜.”

아무도 듣지 못한 채, 사라지는 말들.

지금의 방법으로는

  • 휴대폰 일기 앱손과 눈이 필요해, 운전 중에는 쓸 수 없습니다.
  • 음성 메모쌓이기만 할 뿐, 다시 듣지 않게 됩니다.
  • 차량 음성 비서‘명령’을 듣는 도구라, 마음을 묻지 않습니다.
  • 운전 중 SNS이어지고 싶어도, 위험해서 하면 안 됩니다.

그래서

그 말을 들어 주는 차를
만들었습니다.

길동무는 차 안에서 혼자 삼키던 말을 들어 일기로 남겨 주고, 원하면 그 말을 길 위에 놓아두어
다음에 그 길을 지나는 사람에게 건넵니다. 날마다 혼자 있는 운전자를 만나는 차 안이야말로,
차가워진 시대에 따뜻함을 건넬 수 있는 좋은 기회라고 생각했습니다.

  1. 01말만으로 끝나는 기록구슬을 한 번 누르고 말하면, 받아 적어 일기에 담습니다.
  2. 02함께 쓰는 차에서도 지켜지는 내 이야기운전자마다 계정이 따로 있고, 목소리로 일기의 주인을 확인합니다.
  3. 03길 위의 느슨하고 따뜻한 연결누군가 그 자리에 남긴 한마디가, 지나갈 때 저절로 켜집니다.

로고 「따옴길」

말이 길이 되어,
누군가에게 닿습니다.

  1. 따옴표차 안에서 한 말 한마디.
  2. 차선따옴표의 꼬리가 차선이 되어 길을 따라 뻗습니다.
  3. 길 끝의 불빛그 말이 닿는 곳. 그 길을 지나는 누군가.

  1. 01

    차에 타면, 먼저 인사를 건넵니다

    운전자를 알아보고, 큰 글씨와 목소리로 인사합니다. 길동무의 목소리는 운전자와 다른 성별로 맞추고, 설정에서 바꿀 수 있습니다.

    “어서 오세요, 도현님. 늦게까지 수고 많았어요.”길동무
  2. 02

    길동무가 먼저 묻습니다

    평소 출발 시각의 기록과 견주어, 오늘이 평소와 다른 날이라는 것을 압니다. 혼자 탔을 때만 묻습니다.

    “오늘은 평소보다 3시간쯤 늦게 퇴근하시네요. 오늘 하루, 많이 고단하셨나요?”길동무

    말하면, 받아 적힙니다

    말하는 동안 내 말이 화면에 적히고, 말을 멈추면 스스로 듣기를 마치고 일기에 담습니다.

    “하… 오늘 정말 하루가 힘들었어. 팀장한테 깨지고, 야근도 하고… 힘들다.”도현
  4. 04

    AI가 마음결을 읽고, 길동무가 답합니다

    기기 안의 AI가 읽은 마음결은 지침. 말은 내 일기에만 담기고, 단추 하나로 길 위에도 남길 수 있습니다.

    “혼나고, 야근까지. 오늘 정말 애쓰셨어요.”길동무
  5. 05

    달리는 동안에는 한 줄, 신호에 서면 한마디

    집에 가는 길. 달리는 동안에는 글 없이 한 줄과 목소리뿐이고, 빨간 신호에 서 있는 동안에만 글이 보입니다.

    “오늘 모두 야근 고생하셨고, 집 가서 행복하게 사랑하는 사람과 마무리하세요.”익명의 길동무 · 34분 전

기능

명령이 아니라,
마음을 듣는 차.

말을 남기는 곳은 내가 정합니다

‘내 일기에만’(기본)과 ‘길 위에도 남기기’ 가운데 고릅니다. 길 위에는 이름 없이 남습니다. 욕설이나 누군가를 깎아내리고 위협하는 말은 어디에도 담지 않고, 다듬어서 다시 말해 달라고 청합니다. 전화번호 같은 개인 정보(말로 읽은 숫자 포함)와 광고는 AI 필터가 알아서 걸러, 까닭을 알리고 일기에만 담습니다.

목소리로 일기 주인 확인

다른 목소리가 들리면 “혹시 서윤님이신가요?” 하고 누구의 일기에 담을지 먼저 묻습니다. 녹음은 남기지 않습니다.

일기장과 마음 달력

그날의 말들이 시간의 줄에 꿰이고, 한 달은 마음결로 물든 달력으로 돌아봅니다.

길 위의 한마디

내비게이션이 아닙니다. 누군가 그 자리에 남긴 한마디를 둘러보고, 공감하거나 이어서 한마디를 남깁니다.

친구들의 오늘

같은 앱을 쓰는 친구끼리 오늘의 한마디와 공감을 나눕니다. 주차 중에만 열립니다.

살아 있는 바탕

화면 뒤의 풍경은 사진이 아니라, 앱이 그 자리에서 그리는 장면 열 가지입니다. 처음에는 길동무의 얼굴인 ‘빗빛 · 밤’이 깔리고, 계절·시각·날씨를 따라 바뀌게 둘 수도 있습니다. 지금 이 페이지의 배경이 바로 그 장면입니다. 눌러서 바꿔 보세요.

휴대폰이 아니라 차여야 하는 이유

  • 기어출발과 도착을 알아, 운행 기록을 쌓습니다

  • 빠르기달리는 동안에는 글을 치우고, 서 있을 때만 보입니다

      /** 글자 1~3개 묶음 (낱말의 처음과 끝을 알 수 있게 앞뒤에 칸을 붙인다) */
fun feats(s: String): Set<String> {
    val t = " " + norm(s) + " "
    val fs = HashSet<String>()
    for (n in 1..3) for (i in 0..t.length - n) {
        val g = t.substring(i, i + n)
        if (g.isNotBlank()) fs.add(g)
    }
    return fs
}

fun predict(text: String): FloatArray {
    val fs = feats(text)
    val v = 1f / sqrt(maxOf(1, fs.size).toFloat())
    val z = bias.copyOf()
    for (f in fs) w[f]?.let { row -> for (k in z.indices) z[k] += row[k] * v }
    val mx = z.max()                       // 일곱 마음결의 확률로
    var sum = 0f
    for (k in z.indices) { z[k] = exp(z[k] - mx); sum += z[k] }
    for (k in z.indices) z[k] /= sum
    return z
}
      /** 말로 읽은 숫자도 숫자로 본다: 음성 인식은 '0102481 삼오칠구'처럼 숫자와 말을 섞어 적기도 한다 */
private val digitWord = mapOf('공' to '0', '영' to '0', '일' to '1', '이' to '2', '삼' to '3', '사' to '4',
                              '오' to '5', '육' to '6', '륙' to '6', '칠' to '7', '팔' to '8', '구' to '9')

/** 숫자를 읽은 말(세 글자 이상 이어질 때만)을 숫자로 바꾸고, 숫자 사이의 칸·점·줄표를 없앤다 */
private fun digits(text: String): String {
    val sb = StringBuilder(text.length)
    var i = 0
    while (i < text.length) {
        var j = i
        while (j < text.length && text[j] in digitWord) j++
        if (j - i >= 3) { for (k in i until j) sb.append(digitWord[text[k]]); i = j }
        else { sb.append(text[i]); i++ }
    }
    return sb.toString().replace(Regex("(?<=\\d)[\\s.-]+(?=\\d)"), "")
}
